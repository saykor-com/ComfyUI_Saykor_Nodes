## Included Nodes

### `(Saykor) Safe Image Loader & Switch`

A robust image loader that **never breaks your workflow**. It safely loads an image and automatically switches between **Text-to-Image (T2I)** and **Image-to-Image (I2I)** latent modes — with graceful fallback if anything goes wrong.

This is the recommended alternative to ComfyUI's built-in `Load Image` when you need an **optional image input** that won't crash the graph if nothing is selected or if the image fails to load.

> **v2.0 Update:** Now with **IMAGE input socket** (connect any image node), **resize controls**, and **original-size preview**!

---

#### How It Works (Decision Flow)

```
┌─────────────────────────────────────────────────┐
│          Safe Image Loader & Switch             │
└─────────────────────────────────────────────────┘
                        │
                        ▼
     ┌─────────────────────────────────────┐
     │  Source image priority:             │
     │  1) IMAGE socket (if connected)     │
     │  2) image_selection dropdown        │
     └─────────────────────────────────────┘
            │                │
      Image found        No image
            │                │
            ▼                ▼
     ┌──────────────┐  ┌──────────────────┐
     │ VAE          │  │ Pass-through T2I │
     │ connected?   │  │ latent           │
     └──────┬───────┘  │ has_image=False  │
            │          └──────────────────┘
       ┌────┴────┐
      Yes        No
       │          │
       ▼          ▼
  ┌────────┐ ┌───────────────────┐
  │Resize  │ │ Pass-through T2I  │
  │(prop.) │ │ latent unchanged  │
  │or exact│ │ (no VAE mode)     │
  │ + VAE  │ └───────────────────┘
  │Encode  │
  └───┬────┘
      ▼
  ┌──────────────────────────────────┐
  │  Return (latent, preview, bool)  │
  │  preview = ORIGINAL (unresized)  │
  └──────────────────────────────────┘
```

---

#### Detailed Behaviour

| Scenario | `latent` output | `preview_image` output | `has_image` |
|----------|----------------|------------------------|-------------|
| **No image** (socket disconnected + dropdown `[None]`) | Passes through original `t2i_latent` unchanged | Blank black 512×512 placeholder | `False` |
| **IMAGE socket connected + VAE** | Resized (or exact) → VAE Encode → **I2I latent** | Original image **unresized** | `True` |
| **IMAGE socket connected + NO VAE** | Pass-through of original `t2i_latent` | Original image unresized | `True` |
| **Dropdown only + VAE** | Loads from file → Resize → VAE Encode → **I2I latent** | Original image unresized | `True` |
| **Dropdown only + NO VAE** | Pass-through of original `t2i_latent` | Loaded image unresized | `True` |
| **Image load error** | Graceful fallback → `t2i_latent` | Blank black 512×512 placeholder | `False` |

> **🔑 Key benefit:** All image inputs are **fully optional**. Leave everything disconnected and the node silently passes through the T2I latent. Perfect for shared workflows where you sometimes want I2I and sometimes T2I.

---

#### Inputs

| Input | Type | Required | Description |
|-------|------|----------|-------------|
| `t2i_latent` | `LATENT` | ✅ | Empty latent generated by `Empty Latent Image` (used for Text-to-Image mode) |
| `image` | `IMAGE` | ❌ | **NEW** — External image input socket. Connect any image node (Load Image, Load Image Safe, etc.). Takes priority over `image_selection` dropdown |
| `image_selection` | `LIST` | ❌ | Dropdown menu with all images from `ComfyUI/input/` + `[None]` option. Used only when `image` socket is disconnected |
| `vae` | `VAE` | ❌ | VAE model for encoding the image into latent space. Required for Image-to-Image mode — if omitted, the node falls back to T2I pass-through |
| `resize_width` | `INT` | ❌ | Target resize width in pixels (must be multiple of 64). `0` = auto to nearest multiple of 64. If only one dimension is set, the other scales **proportionally** to maintain aspect ratio |
| `resize_height` | `INT` | ❌ | Target resize height in pixels (must be multiple of 64). `0` = auto to nearest multiple of 64. If only one dimension is set, the other scales **proportionally** |

#### Outputs

| Output | Type | Description |
|--------|------|-------------|
| `latent` | `LATENT` | The selected latent — either the original `t2i_latent` (T2I mode) or the VAE-encoded image latent (I2I mode) |
| `preview_image` | `IMAGE` | **Original unresized preview** of the loaded image, or a black 512×512 placeholder if no image is selected |
| `has_image` | `BOOLEAN` | `True` if an image was successfully loaded, `False` otherwise. Useful for conditional routing with other nodes |

---

#### Image Source Priority

1. **IMAGE socket** (highest) — If connected, its image is used regardless of the dropdown selection
2. **Dropdown** — Falls back to `image_selection` dropdown when the IMAGE socket is disconnected

This means you can now:
- Connect a **(Saykor) Load Image (Safe)** → resize → **(Saykor) Safe Image Loader & Switch** for full control
- Use the same workflow with **dropdown-only** for quick manual image selection
- Send the image to **CLIP Vision / Florence2** first, then pipe the result through to this node

---

#### Resize Logic

| `resize_width` | `resize_height` | Behaviour |
|:---:|:---:|:---|
| `0` | `0` | Auto — resizes to the nearest multiple of 64 (original aspect ratio preserved approximately) |
| `512` | `0` | Width 512px, height **proportional** (aspect ratio maintained, snapped to nearest 64) |
| `0` | `512` | Height 512px, width **proportional** (aspect ratio maintained, snapped to nearest 64) |
| `512` | `512` | **Exact** 512×512 resize (may distort aspect ratio) |

> Note: After VAE encoding, the returned `preview_image` is **always the original unresized image**, so you can inspect it without distortion.

```
┌─────────────────────────┐
│  (Saykor) Load Image (Safe) │──┐

┌──────────────────┐     │  └────────────────────────────┘  │
│  Empty Latent    │────>│                                  │
│  Image           │     │  ┌─ latent ─────────────────┐    │──→ KSampler
│  (t2i_latent)    │     │  │  preview_image (original) │    │
└──────────────────┘     │  │  has_image (bool)        │    │
                         └──────────────────────────────────┘
┌──────────────────┐     │
│  VAE             │────>│
└──────────────────┘
```

**Use case scenarios:**

1. **Pure Text-to-Image:** Leave everything disconnected → node passes T2I latent through
2. **Image-to-Image with dropdown:** Select image from dropdown + connect VAE → auto I2I
3. **Image-to-Image with external processing:** Connect an image from "(Saykor) Load Image (Safe)", resize it, send to CLIP Vision for prompt generation, pipe the processed image to this node with VAE
4. **High-res I2I:** Connect image + set `resize_width` to 1024 with proportional height — node resizes exactly as needed for VAE

### `(Saykor) Latent Selector (T2I/I2I)`

Automatically selects between Text-to-Image and Image-to-Image latents based on whether an image input is provided.

- Image provided → uses I2I latent (image-to-image mode)
- No image → uses T2I latent (text-to-image mode)

**Inputs:**

| Input | Type | Required | Description |
|-------|------|----------|-------------|
| `t2i_latent` | LATENT | ✅ | Empty latent for Text-to-Image |
| `i2i_latent` | LATENT | ✅ | Encoded latent from an image (I2I) |
| `image` | IMAGE | ❌ | Image from any Load Image node |

**Outputs:**

| Output | Type | Description |
|--------|------|-------------|
| `latent` | LATENT | The selected latent |
| `mode_text` | STRING | `"Image-to-Image Mode"` or `"Text-to-Image Mode"` |

### `(Saykor) LTX Sequencer with IC-LoRA`

High-performance LTX video sequencer with integrated IC-LoRA Video guidance. Bypasses slow timeline managers for raw generation speeds.

Includes a rich JavaScript UI with dynamic keyframe widgets, multi-node state sync, auto-detection of connected Multi Image Loaders, and real-time frame/seconds mode switching.

**Inputs:**

| Input | Type | Required | Description |
|-------|------|----------|-------------|
| `positive` | CONDITIONING | ✅ | Positive conditioning |
| `negative` | CONDITIONING | ✅ | Negative conditioning |
| `vae` | VAE | ✅ | VAE for encoding/decoding |
| `latent` | LATENT | ✅ | Input latent tensor |
| `multi_input` | IMAGE | ✅ | Multi-image batch for keyframes |
| `num_images` | INT | ✅ | Number of images to process (0-50) |
| `insert_mode` | STRING | ✅ | `"frames"` or `"seconds"` mode |
| `frame_rate` | INT | ✅ | Frame rate for seconds mode (1-120) |
| `strength_sync` | BOOLEAN | ✅ | Sync strength across all keyframes |
| `bypass` | BOOLEAN | ✅ | Bypass the node entirely (pass-through) |
| `control_video` | IMAGE | ✅ | Canny/Depth/Pose video for IC-LoRA guidance |
| `ic_lora_strength` | FLOAT | ✅ | IC-LoRA guidance strength (0.0–2.0) |
| `video_start_frame` | INT | ✅ | Start frame for the control video |
| `insert_frame_N` | INT | ❌ | Insert position in frames for image N |
| `insert_second_N` | FLOAT | ❌ | Insert position in seconds for image N |
| `strength_N` | FLOAT | ❌ | Per-image keyframe strength (0.0–1.0) |

**Outputs:**

| Output | Type | Description |
|--------|------|-------------|
| `positive` | CONDITIONING | Positive conditioning with applied guidance |
| `negative` | CONDITIONING | Negative conditioning with applied guidance |
| `latent` | LATENT | Output latent with keyframes applied |

### `(Saykor) Is Image Valid ?`

Simple validation node that checks whether an image input is valid (not `None`) and returns both a `BOOLEAN` and `INT` representation for maximum compatibility with downstream nodes.

**Inputs:**

| Input | Type | Required | Description |
|-------|------|----------|-------------|
| `image` | IMAGE | ❌ | Image to validate |

**Outputs:**

| Output | Type | Description |
|--------|------|-------------|
| `is_valid` | BOOLEAN | `True` if image is not `None` |
| `as_int` | INT | `1` if valid, `0` if not |

### `(Saykor) Load Image (Safe)`

Extended version of ComfyUI's built-in `Load Image` node that adds a `"[none]"` option in the dropdown menu. This allows Text-to-Image mode to continue cleanly when no image should be passed downstream. Also includes a "Clear" button in the frontend to reset back to `[none]`.

Works as a fully separate node — the original `Load Image` remains completely untouched.

**Features:**
- `[none]` is the **default selection** — ideal for T2I-first workflows
- Full support for **animated WebP** and all formats the original Load Image supports
- **Clear button** in the UI to quickly reset back to `[none]`
- **`[none]` never crashes** — returns a 1×1 empty image + mask placeholder
- Comprehensive `SEARCH_ALIASES` — find it by searching "load image", "safe load", "import image", etc.

**Inputs:**

| Input | Type | Required | Description |
|-------|------|----------|-------------|
| `image` | LIST | ❌ | Dropdown of input images + `[none]` option. Default: `[none]` |

**Outputs:**

| Output | Type | Description |
|--------|------|-------------|
| `image` | IMAGE | Loaded image or empty 1×1 placeholder when `[none]` |
| `mask` | MASK | Alpha mask or empty mask tensor |

## Installation

### Option 1: Git Clone (recommended)

```bash
cd ComfyUI/custom_nodes/
git clone https://github.com/saykor-com/ComfyUI_Saykor_Nodes.git
```

Then restart ComfyUI.

### Option 2: Manual Install

1. Download or copy the `ComfyUI_Saykor_Nodes` folder into `ComfyUI/custom_nodes/`
2. Restart ComfyUI

### Option 3: ComfyUI Manager

Search for `Saykor Nodes` in ComfyUI Manager and install directly.
